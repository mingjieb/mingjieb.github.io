This is a graduate course (instrutor: Prof. Chad Jenkins) provided by Robotics Department, University of Michigan. This project series stems from an advanced robotics course focused on enabling autonomous mobile agents to perceive, reason, and act. The coursework covers a full pipeline from low-level control to high-level motion and task planning. The assignments emphasize hands-on implementation of algorithms in kinematics, dynamics, path planning, and motion planning using JavaScript and the KinEval robot simulation toolkit.

## Robot Kinematics and Dynamics

<div class="row">
  <div class="col-12">
    <span style="font-size: 1.5em;">Key Topics:</span>
    <ul>
      <li>Forward kinematics using transformation matrices</li>
      <li>Inverse kinematics via Jacobian pseudoinverse and gradient descent</li>
      <li>Kinematic chain construction (link/joint model)</li>
      <li>Lagrangian mechanics and dynamics for simple systems</li>
      <li>Proportional-Derivative (PD) control</li>
    </ul>

## Motion Planning

<div class="row">
  <div class="col-12">
    <span style="font-size: 1.5em;">Key Topics:</span>
    <ul>
      <li>Configuration space (C-space) representation</li>
      <li>Sampling-based planning foundations (e.g., PRM/RRT-style logic)</li>
      <li>Collision-aware trajectory generation</li>
      <li>Trajectory interpolation between waypoints</li>
      <li>Planning in high-dimensional joint space</li>
    </ul>
  </div>
  <div class="col-12">
    <span style="font-size: 1.5em;">Assignments:</span>
    <ul>
      <li><strong>Motion Planning for Robot Arm:</strong>
      Developed a collision-aware motion planner in joint configuration space
        <ul>
          <li>Sampled feasible configurations and connected them to form valid paths</li>
          <li>Implemented interpolation for smooth trajectories</li>
          <li>Evaluated planning success under varying obstacles</li>
        </ul>
      </li>
      <li><strong>Workspace and C-space Visualization:</strong>
      Explored how joint limits, obstacles, and robot geometry influence the reachable workspace and feasible paths
      </li>
    </ul>
  </div>
</div>
